OpenMalwareScannerPortable

Multi-engine static malware scanner in a single DLL: ClamAV signatures, YARA-X rules, Unicorn CPU-emulation unpacker, ML models, Hayabusa event rules and Authenticode + catalog verification — behind a plain C FFI.

Download Release Source Code

Engines

ClamAV signatures

Rust ClamAV engine with bytecode VM, daily signature databases and archive recursion.

YARA-X rules

Compiled Valhalla threat-intel ruleset scanned over raw, unpacked and overlay bytes.

Unicorn unpacker

x86/x64 CPU emulation dumps packed payloads back into the scan pipeline.

ML models

Gradient-boosted tree ensembles for PE, JavaScript and URL/phishing classification.

Hayabusa / Sigma

Windows EVTX forensics and live system-event log scanning.

Authenticode + catalog

WinVerifyTrust plus CatRoot catalog fallback, so catalog-signed OS binaries verify as trusted.

Heuristics

Null-padding strip, PE overlay binder check (validated MZ→PE only), decompression-bomb guard.

System checks

PUA autostart registry rules and hosts-file hijack detect & restore.

C FFI API

FunctionWhat it does
openedr_static_initLoad rules/models from a directory (NULL = next to the DLL).
openedr_static_scan_fileFull multi-engine scan of a file path → JSON.
openedr_static_scan_bytesScan an in-memory buffer → JSON.
openedr_static_scan_urlURL / phishing score → JSON.
openedr_static_scan_evtxScan an .evtx file with Hayabusa rules.
openedr_static_scan_system_eventsScan live Windows event logs.
openedr_static_check_registryCheck a Run/persistence key against PUA rules.
openedr_static_check_hosts_fileDetect hosts-file hijacking (NULL = default).
openedr_static_restore_hosts_fileRestore the clean hosts template (optional backup).
openedr_static_free_stringFree every heap string the API returns.
Note: there is no cloud lookup. The retired Comodo FLS client was removed; verdicts come only from local engines.

Verdicts

VerdictMeaning
MaliciousScore ≥ 0.85 — signature hit or high-confidence stack.
SuspiciousScore ≥ 0.50 or heuristic-only evidence.
CleanSHA-256 whitelist hit or trusted signature with no other signal.
UnknownNo engine fired. Unsigned + unknown = unknown, not malicious.

False positives

Signed binaries fast-path to Clean; 256k known-good SHA-256 hashes are whitelisted; overlay/archive findings require a validated embedded PE or an engine hit — installer-shaped files (7z SFX, Inno, NSIS) don't trip the heuristic alone.
