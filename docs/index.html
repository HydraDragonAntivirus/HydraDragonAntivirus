Multi-engine static malware scanner in a single DLL with a C FFI — plus a Web/WASM edition that runs fully client-side.

Download Release Source Code

Added

Catalog signer verification

WinVerifyTrust plus CatRoot catalog fallback. Catalog-signed OS binaries verify as trusted with the catalog signer name — for every file type, extension or not. Reported as signer_info.is_catalog_signed.

Web / WASM edition

OpenEDR/openedr_web compiles the static core to wasm32: same tree models and YARA-X engine, registry rules rewritten as in-PE string rules. Optional capstone.js disassembly and unicorn.js unpack assists in the browser demo.

Daemon mode, 7 languages

Polling watchers in Python, Node.js, C#, Go, Rust, C++ and C: watch dir → scan new files → print hits, with SHA-256 skip caches and optional quarantine.

Full SDK coverage

Every wrapper now exposes all 10 exports: file/bytes/URL scan, EVTX + live system-event scan, registry check, hosts check & restore.

Overlay false-positive fix

Embedded-executable findings require a validated MZ→PE image. Installer shapes (7z SFX, Inno, NSIS) no longer trip the heuristic alone.

Recalibrated verdicts

PE_ML threshold 0.70→0.71; score-gated verdicts — Malicious ≥ 0.85, Suspicious ≥ 0.50. Unsigned + unknown stays Unknown, never malicious by default.

Dead cloud removed

Retired Comodo FLS client deleted from engine, exports and all SDKs. SHA-256-only identity, verdicts from local engines only.

Phishing panic fixed

Out-of-bounds crash on unclosed <a> tags in archive HTML clamped; affected archives scan clean instead of erroring.

Verdicts

Malicious (≥0.85) — signature hit or high-confidence stack. Suspicious (≥0.50 or heuristic-only). Clean — whitelist hit or trusted signature, nothing else. Unknown — no engine fired.

Every scan returns target, file_size, sha256, verdict, max_threat_score, detections[{layer, name, score, details}], signer_info as JSON.
